## これはリスク【弱点6】と同じ構造

> リスク1周目の最大の発見＝失点の質は「知らない」ではなく

今回は「除外して数字を作る」ではなく「**近い選択肢に寄せる**」形だが、**入口は同じ**。
**科目を問わない失点構造**であることが、相続の初回で確認された。

## なぜ最も危険な当たり方なのか

- **4択なので、この打ち手はときどき当たる**（今回は当たった）
- **当たると、穴が記録から消える**。☆すら付かないので後から検知できない
- リスクでも **2025②Q7・2023②Q6・2024①Q30** が「正解だが計算は誤り」だった

## ⚠️ ただし原因は「Q22のどこかの計算ミス」ではない

**個別の分岐点を追わない。** 非☆30問の実質正答率が26.7%（4択の期待値とほぼ同じ）である以上、
**Q22だけが特別に狂ったのではなく、そもそも計算を最後まで正しく走らせる土台が無い**。
→ **対策は個別の訂正ではなく、【弱点5】の解法の総ざらい**。

## 運用ルール（リスクで有効だったものをそのまま持ち込む）

1. **合わないときは、処理を削らない／選択肢に寄せない**
2. **それでも合わなければ、寄せずに捨てて☆を付ける**（**寄せると穴が消える**）
3. **寄せた問題には印をつけ、採点後に正誤にかかわらず全ステップを再現する**

# 🔴🔴🔴 【最優先】法定相続人の数え方 ― **1つ潰すと4問が動く**

**Q21（基礎控除額）を☆で誤答**。選択2（54,000千円＝4人）／**正解4（66,000千円＝6人）**。

この設例は**法定相続人の数え方の例外を4つ重ねている**。式（3,000万＋600万×人数）は易しく、**人数の確定が本体**。

```
① 相続放棄は「なかったもの」として数える            → 長女（放棄）も算入
② 配偶者の実子で被相続人の養子となった者は「実子」とみなす → 養子A（妻と前夫の子）
③ 養子が相続開始前に死亡し代襲相続人がいる場合、
   その代襲相続人は「実子」とみなす                → 養子B死亡 → 孫D（養子D）
④ 実子がいる場合、算入できる普通養子は1人まで        → 残るのは養子C（孫C）1人

妻1 ＋ 実子とみなす4（長女・二女・養子A・養子D）＋ 養子1 ＝ 6人
基礎控除 ＝ 30,000千円 ＋ 6,000千円 × 6 ＝ 66,000千円
```

**②③を知らないと、養子A・養子Dを「養子1人まで」の枠に押し込んで4人になる**（＝選択2に着地）。

## ✅【2026-08-24 真因確定】Q14 ― 人数は分かっていた。割れる箇所を踏み外した

**本人申告＝「法定相続人＝5人はわかっていたが、控除を4人で計算した。相続放棄をした二女を人数から除いてしまった」。**

→ **診断が1段深くなった。「数え方を知らない」のではない。**

| | 何を使うか | 二女（放棄）の扱い |
|---|---|---|
| **人数**（500万×人数） | 相続税法上の【法定相続人の数】 | **含める**（放棄がなかったものとして数える・相続税法15条2項） |
| **分母／適用対象**（按分） | 実際に【相続人として】受け取った者 | **含めない**（放棄により相続人でない） |

**★同じ人物が、人数には入るが分母には入らない。ここだけ扱いが割れる。**

**⭕ 分母の判断は正しくできていた**（長男の妻10,000千円と二女5,000千円を除いて60,000千円）。
**その正しい判断を人数にも適用したのが誤りの構造**＝**「知らなかった」より根が浅い。割れる箇所を1つ覚えれば済む。**

```
① 人数 ＝ 妻・孫A・孫B（代襲）・長女・二女（放棄も含める）＝ 5人 → 500万×5 ＝ 25,000千円
② 分母 ＝ 45,000＋5,000＋5,000＋5,000 ＝ 60,000千円（長男の妻・二女を除く）
③ 妻の非課税 ＝ 25,000 × 45,000/60,000 ＝ 18,750千円
④ 45,000 − 18,750 ＝ 26,250千円（正解2）／選んだ30,000千円は①を4人にした値
```

**🔗 リスク26①Q20と同じ構造**（あちらは**相続人でない孫**を分母から除く論点で★2回連続失点）。
**リスクと相続が重なる帯＝ここを固めると両方に効く。**

## 数える手順を固定する（暗記ではなく順番）

```
① 相続人を全員書き出す（放棄した者も書く）
② 放棄を「なかったもの」として扱う
③ 養子を仕分ける

⑤ 妻 ＋ 実子とみなす者 ＋ ④で残した養子 ＝ 法定相続人の数
```

**③を②と④の間に置くのが要**。飛ばすと養子A・養子Dが制限枠に入って4人になる。
