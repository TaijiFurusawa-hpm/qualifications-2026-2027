# 🔴🔴🔴 【最優先】法定相続人の数え方 ― **1つ潰すと4問が動く**

**Q21（基礎控除額）を☆で誤答**。選択2（54,000千円＝4人）／**正解4（66,000千円＝6人）**。

この設例は**法定相続人の数え方の例外を4つ重ねている**。式（3,000万＋600万×人数）は易しく、**人数の確定が本体**。

```
① 相続放棄は「なかったもの」として数える            → 長女（放棄）も算入
② 配偶者の実子で被相続人の養子となった者は「実子」とみなす → 養子A（妻と前夫の子）
③ 養子が相続開始前に死亡し代襲相続人がいる場合、
   その代襲相続人は「実子」とみなす                → 養子B死亡 → 孫D（養子D）
④ 実子がいる場合、算入できる普通養子は1人まで        → 残るのは養子C（孫C）1人

妻1 ＋ 実子とみなす4（長女・二女・養子A・養子D）＋ 養子1 ＝ 6人
基礎控除 ＝ 30,000千円 ＋ 6,000千円 × 6 ＝ 66,000千円
```

**②③を知らないと、養子A・養子Dを「養子1人まで」の枠に押し込んで4人になる**（＝選択2に着地）。

|---|---|---|

| Q15 | 退職手当金の非課税枠 ＝ 500万×**人数**（**生保金とは別枠**） | 誤答 |
| Q22 | 相続税の総額 ＝ 課税遺産総額を**法定相続分**で按分 | ✅正解 |

## ⚠️ ただしQ21とQ22は矛盾している ― **最優先の確認事項**

Q22の正解1（163,000千円）は、**法定相続人6人**で計算した値です。

```
妻   300,000千円（1/2）→ ×50% − 42,000 ＝ 108,000千円
子5人  60,000千円ずつ  → ×30% −  7,000 ＝  11,000千円 ×5 ＝ 55,000千円
                                        合計 163,000千円 ＝ 正解1
```

**もしQ21のとおり4人で計算していたら、Q22は選択肢3（177,000千円）に着地します。**
1を選べたということは、**Q22の時点では6人で数えられていた可能性がある**。

> **🔴 次に確認したいこと＝Q22をどう解いたか。**
> ここで法定相続人の数え方が入っているのか、それとも別の理由で1を選んだのかで、
> 対策が変わります（**知識の穴なのか、Q21の場面で自信を失っただけなのか**）。
