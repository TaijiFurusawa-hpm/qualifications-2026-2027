# 🔴🔴🔴 【弱点4】**数字合わせ** ― 計算が合わないとき、選択肢に寄せてしまう

**Q22（相続税の総額）の申告＝「6人で計算したが結果が選択肢と合わなかったので、近い1を選んだ」。**
選択肢1が正解だったため素点は正答。**しかし計算は合っていない。**

## これはリスク【弱点6】と同じ構造

> リスク1周目の最大の発見＝失点の質は「知らない」ではなく
> **「ロジックが不確か → 計算が合わない → 選択肢に合う数字を作りにいく」**

今回は「除外して数字を作る」ではなく「**近い選択肢に寄せる**」形だが、**入口は同じ**。
**科目を問わない失点構造**であることが、相続の初回で確認された。

## なぜ最も危険な当たり方なのか

- **4択なので、この打ち手はときどき当たる**（今回は当たった）
- **当たると、穴が記録から消える**。☆すら付かないので後から検知できない
- リスクでも **2025②Q7・2023②Q6・2024①Q30** が「正解だが計算は誤り」だった

## ⚠️ ただし原因は「Q22のどこかの計算ミス」ではない

**個別の分岐点を追わない。** 非☆30問の実質正答率が26.7%（4択の期待値とほぼ同じ）である以上、
**Q22だけが特別に狂ったのではなく、そもそも計算を最後まで正しく走らせる土台が無い**。
→ **対策は個別の訂正ではなく、【弱点5】の解法の総ざらい**。

## 🆕【2026-08-24】「寄せる」の型は2つある

**Q22の真因が確定した＝163,000千円（正解）を一度は出していた。そのあと孫養子2人分の2割加算（4,400千円）を足して167,400千円になり、選択肢に無いので適当回答した。**

| | 型 | 中身 |
|---|---|---|
| リスクで見た型 | **処理を削る** | ロジックが不確か → 合わない → 処理を削って選択肢に合わせにいく |
| **今回の型** | **処理を足しすぎる** | **正解を一度出していたのに、余計な一手を加えて選択肢から外れた** |

**→ 運用ルールに追加：【選択肢に無い数字が出たら、まず『余計な処理を足していないか』を疑う】。**
削る前に、足しすぎを疑う。今回は削る方向に動いていたら永遠に合わなかった。

## 🔴🔴🔴【2026-08-28】型1が実際に発動し、**しかも正解に着地した** ― Q16

**最も危険な形が出た。「合わせるために、正しいものを削った」。そして当たった。**

```
① 遺言執行費用700千円を控除に入れていた（誤り）→ 計算が合わない
② 検算で遺言執行費用を落とした
③ それでも合わない（葬式費用を1,800千円としていた。正しくは1,600千円＝香典返し300千円の除外漏れ）
④ ★合わせるために【本来控除できる固定資産税200千円】を除外した
⑤ 5,700千円＝正解肢に着地した
```

**★誤差200千円が、たまたま固定資産税200千円と同額だった。** つまり**2か所の誤りが相殺して正解になった**。

| | 正しい内訳 | 実際にやった内訳 |
|---|---|---|
| 銀行借入金 | 3,500 | 3,500 |
| **固定資産税** | **200** | **0（★削った）** |
| 準確定申告の所得税 | 400 | 400 |
| **葬式費用** | **1,600** | **1,800（★香典返しの除外漏れ）** |
| 合計 | **5,700** | **5,700**（＝同じ） |

**→ 運用ルールに追加：【正解肢に着地しても、内訳をもう一度読み上げる】。**
**『合わせるために何かを削った』なら、それは正解ではない。** 4択なので相殺は起こりうる。
**そして相殺して当たった場合、☆すら付かないので穴が完全に消える**（【弱点2】非☆の穴が生まれる瞬間がこれ）。

### Q22の内容面の要点 ― 2割加算は「相続税の総額」に入りようがない

```
【第1段階】課税価格の合計 − 基礎控除 ＝ 課税遺産総額
【第2段階】課税遺産総額を「法定相続分」で按分 → 速算表 → 合計 ＝ 相続税の総額  ← Q22はここ
【第3段階】相続税の総額 ×「実際の取得割合」＝ 各人の算出税額
【第4段階】各人ごとに 2割加算 → 各種税額控除 ＝ 各人の納付税額               ← Q23はここ
```

**なぜ入らないか**＝相続税の総額は【遺産全体にかかる税額の総枠】で、**誰がいくら取得しても変わらない**ように設計されている（分け方で税額が動かないようにするため）。**2割加算は「誰が取得したか」による調整なので、総額の段階には存在し得ない**。
**判断の合図は設問文**＝「相続税の**総額**」なら第2段階まで／「各人の**納付税額**」なら第4段階まで。

## 運用ルール（リスクで有効だったものをそのまま持ち込む）

1. **合わないときは、処理を削らない／選択肢に寄せない**
2. **それでも合わなければ、寄せずに捨てて☆を付ける**（**寄せると穴が消える**）
3. **寄せた問題には印をつけ、採点後に正誤にかかわらず全ステップを再現する**
4. **🆕 選択肢に無い数字が出たら、まず「余計な処理を足していないか」を疑う**（Q22＝正解を出したあと2割加算を足して外れた）

# 🧭【SC7・SC1】法定相続人の数え方 ― 解法フレーム（2026-08-24 真因確定）

> **この科目の最上流。1つ潰すとQ14・Q15・Q21・Q22が同時に動く。**

## 5ステップ（順番が命）

```
① 相続人を全員書き出す（放棄した者も書く）
② 放棄を「なかったもの」として扱う                    ← 相続税法15条2項
③ ★養子を仕分ける ― みなし実子か、ただの養子か         ← 相続税法15条3項
④ 残った普通養子【だけ】に数の制限（実子あり1人／実子なし2人）
⑤ 配偶者 ＋ 実子/みなし実子 ＋ ④で残した養子 ＝ 法定相続人の数
```

**★③を②と④の間に置くのが要。** ③を飛ばして④に行くと、**みなし実子まで制限枠に押し込む**。

## ③ みなし実子の4類型（相続税法15条3項）

| | 類型 | 2026①での該当 |
|---|---|---|
| ㋐ | 特別養子縁組による養子 | — |
| **㋑** | **配偶者の実子で、被相続人の養子となった者（連れ子養子）** | **養子Ａ** |
| ㋒ | 婚姻前に配偶者の特別養子だった者で、婚姻後に被相続人の養子となった者 | — |
| **㋓** | **代襲相続人となった直系卑属** | **養子Ｄ** |

**★みなし実子は養子の数の制限を受けない＝枠外。**
**★制度の趣旨**＝養子数の制限は「**節税目的で養子を増やすこと**」を防ぐ規定。**節税目的でない縁組（連れ子・代襲・特別養子）は枠外に置かれる**。

## ★★孫養子の分岐 ― この科目で最も問われるところ

| | 親 | 親の生死 | 判定 |
|---|---|---|---|
| **養子Ｄ**（孫Ｄ・**養子Ｂ**の子） | 養子Ｂ | **死亡** | 代襲相続人 → **みなし実子（枠外）** |
| **養子Ｃ**（孫Ｃ・**二女**の子） | 二女 | **生存** | 代襲なし → **ただの養子（制限対象）** |

**どちらも「孫」で「普通養子」。見た目は同じ。分岐点は【親が死んでいるか】だけ。**
**🔗 この分岐は相続税額の2割加算にもそのまま効く**（孫養子は2割加算の対象／**代襲相続人である場合を除く**）。

### ◆養子の子が代襲相続人になれる条件

**養子縁組『後』に生まれた子だけ**（民法887条2項但書＝代襲できるのは**被相続人の直系卑属**に限る）。
縁組**前**に生まれていた養子の子は、被相続人との間に親族関係が生じないので代襲できない。
→ 2026①の設例が「**孫Ｄは、養子Ｂと成田さん夫婦との養子縁組後に出生している**」と書いているのは、この条件をクリアさせるため。**この一文を読み飛ばすと孫Ｄを代襲相続人と判定できない。**

## 🔴🔴 勘違いポイント① ― 人数と分母で扱いが割れる【Q14・Q15】

**本人申告＝「法定相続人＝5人は分かっていたが、控除を4人で計算した。相続放棄をした二女を人数から除いた」。**

| | 何を使うか | 放棄した者の扱い |
|---|---|---|
| **人数**（500万×人数） | 相続税法上の**法定相続人の数** | **含める**（放棄がなかったものとする） |
| **分母／適用対象**（按分） | 実際に**相続人として**受け取った者 | **含めない**（放棄により相続人でない） |

**★同じ人物が、人数には入るが分母には入らない。ここだけ扱いが割れる。**

**⭕ Q14では分母の判断は正しくできていた**（長男の妻＝相続人でない、二女＝放棄、の両方を除いて60,000千円）。
**その正しい判断を人数にも一貫させたのが誤りの構造**＝**「知らなかった」より根が浅い。割れる箇所を1つ覚えれば済む。**

**🔗 リスク26①Q20と同じ構造**（あちらは**相続人でない孫**を分母から除く論点で★2回連続失点・R18〜R22）。
**リスクと相続が重なる帯＝ここを固めると両方に効く。**

# 🧭【SC1・SC2】相続税の計算4段階 ― どこに何が入るか（2026-08-24 真因確定）

## 4段階

```
【第1段階】各人の課税価格を合計 − 基礎控除 ＝ 課税遺産総額
【第2段階】課税遺産総額を【法定相続分】で按分 → 速算表 → 合計 ＝ 相続税の総額   ← SC1
【第3段階】相続税の総額 ×【実際の取得割合】＝ 各人の算出税額
【第4段階】各人ごとに 2割加算 → 各種税額控除 ＝ 各人の納付税額                ← SC2
```

## ★第2段階に入れてはいけないもの

**実際の取得割合／2割加算／配偶者の税額軽減／未成年者控除・障害者控除・相次相続控除。すべて第3段階以降。**

**★なぜ入らないか**＝**相続税の総額は「遺産全体にかかる税額の総枠」で、誰がいくら取得しても変わらないように設計されている**（＝法定相続分課税方式。**分け方を変えても総額が動かない**ようにして、分割による税負担の操作を防ぐ）。
**2割加算は「誰が取得したか」による調整なので、総額の段階には存在し得ない。**

**★判断の合図は設問文**＝「相続税の**総額**」なら第2段階まで／「各人の**納付税額**」なら第4段階まで。

### ★★二重資格の扱い ― 養子Dは「孫養子」と「代襲相続人」の両方だが、按分は不要

**結論＝不要。2割加算は「人」単位のオール・オア・ナッシング判定で、按分の余地がない。**

**理由① 条文が人単位で書かれている**
18条は「**その者に係る相続税額**」に対して加算するかどうかしか定めておらず、**資格ごとに税額を切り分ける仕組みを持っていない**。
養子Dは2項本文でいったん除外されかけるが、**ただし書によって丸ごと1項に復帰する**。
**復帰するのは「代襲相続人としての資格部分」ではなく、養子Dという人そのもの。**

**理由② そもそも税額を資格別に分解できない**
按分するには次の分子が要る：

```
加算額 ＝ 算出税額 × （孫養子資格に由来する部分 ÷ 全体） × 20%
```

しかし各人の算出税額は **相続税の総額 × その人の課税価格 ÷ 課税価格の合計額** で決まり、
**課税価格は「実際に取得した財産の額」であって、どの資格に基づいて取得したかというタグは付いていない**。
**「これは養子分、これは代襲分」という区別は税務上存在しないので、分子を作ることが物理的に不可能**。

### ★民法の二重資格との対比（ここが整理の要）

| 論点 | 二重資格の扱い | 理由 |
|---|---|---|

## ① 暦年贈与 ― 特例と一般が混在する場合（本人整理 2026-08-29）

```
① 贈与者ごとに区分を判定する
     直系尊属（父母・祖父母）＋ 受贈者18歳以上 → 【特例贈与財産】
     それ以外（叔父・配偶者・義父母・他人）    → 【一般贈与財産】
     ※養親は直系尊属にあたる／配偶者の父母は直系尊属ではない

② 全贈与を合算 → ★基礎控除110万円を【1回だけ】控除 ＝ 課税価格 A

③ A に【一般税率】を適用 → 税額 G
     G × （一般分 ÷ 贈与総額） ＝ 一般分の税額

④ A に【特例税率】を適用 → 税額 T
     T × （特例分 ÷ 贈与総額） ＝ 特例分の税額

⑤ ③ ＋ ④ ＝ 納付税額
```

### ★★核心 ― **控除は1本、税率は2本**

- **基礎控除は総額から1回だけ**。**税率だけを2通り当てて按分する**。
- **「控除を按分する」「控除を2回使う」はどちらも典型的な誤り** → Q29の肢1・肢2がまさにそれ。
- **★按分の分母は基礎控除"前"の贈与総額**（Q29なら12,500千円）。控除後の11,400千円ではない。
  ※分子と分母を控除後で揃えても比率自体は同じになるが、**定義は控除前の財産価額**。
- **★速算表のブラケットは合算後のAで決まる**。**特例分だけ・一般分だけで税率区分を判定しない**。

```
Q29の通し（目黒さん27歳／父4,800・祖母5,200・叔父2,500）
 ① 父・祖母＝直系尊属×18歳以上 → 特例（合計10,000）／叔父 → 一般（2,500）
 ② 12,500 − 1,100 ＝ 【A ＝ 11,400千円】
 ③ 一般税率：11,400 は「10,000超15,000以下」→ 45%・控除1,750
      G ＝ 11,400×0.45 − 1,750 ＝ 3,380 → 3,380 × (2,500÷12,500) ＝ 【676千円】
 ④ 特例税率：11,400 は「10,000超15,000以下」→ 40%・控除1,900
      T ＝ 11,400×0.40 − 1,900 ＝ 2,660 → 2,660 × (10,000÷12,500) ＝ 【2,128千円】
 ⑤ 676 ＋ 2,128 ＝ 【2,804千円】（正解4）
```

**🔴 失点の形＝合計してから計算せず、贈与者ごと（または特例・一般ごと）に個別計算した**。
**★「まず全部足す」から始める。** 区分は税率を選ぶためだけに使い、**控除は1回、ブラケットは合算後のAで決める**。

## ⑥ 【Q44】国外転出（相続）時課税 ― 制度の趣旨から立てる

```
【共通の発想】日本の課税権が届かなくなる瞬間に、含み益を強制的に清算する
```

| 3類型 | 契機 | 申告 |
|---|---|---|
| 国外転出時課税 | 居住者本人が国外転出 | 出国の日までに確定申告 |
| 国外転出（贈与）時課税 | 居住者が**非居住者へ贈与** | 贈与者の確定申告 |
| **国外転出（相続）時課税** | 居住者の死亡により**非居住者が相続・遺贈で取得** | 被相続人の**準確定申告**（相続開始を知った日の翌日から4ヵ月以内） |

**4つの必須要素**

| | 内容 | なぜそうなるか |
|---|---|---|
| **（ア）対象資産** | **有価証券等**（有価証券・匿名組合出資持分・未決済信用取引・未決済デリバティブ） | **不動産は対象外**。国内不動産は非居住者になっても**日本に課税権が残る**（国内源泉所得）ので清算する必要がない。**「持ち出せる＝課税権が消える」財産だけが対象** |
| 金額要件 | **対象資産の合計が1億円以上** | ★**非居住者が取得した部分だけで1億円ではない**。被相続人が所有する対象資産の合計で判定 |
| **（イ）出す側** | **居住者**（かつ相続開始前10年以内に国内居住5年超） | 居住者でなければ、そもそも日本が含み益に課税していた前提が成り立たない |
| **（ウ）受け手** | **非居住者**である相続人等 | 取得者が居住者なら課税は継続するので、発動する必要がない。複数いる場合は**法定相続分で按分し、非居住者部分だけ**が対象 |
| **（エ）税目** | **所得税**（譲渡所得） | 相続税ではない。相続開始時に譲渡したとみなして含み益に課税する |

**★★肢の消去だけなら一瞬で決まる**：設問文に「その相続対象資産の**含み益に対して**（エ）が課される」とある。
**含み益に課すのは所得税であって相続税ではない**ので、**（エ）が相続税の肢1・4はその時点で消える**。残る2・3は（ア）で決着（有価証券等）。→ **正解3**。

**◆緩和措置（3類型共通）**
- **納税猶予**＝担保提供＋納税管理人の届出で**5年**（延長で**10年**）
- **減額・取消**＝猶予期間内に帰国／居住者へ譲渡／実際の譲渡価額が転出時を下回った場合 → **更正の請求（4ヵ月以内）**

# 🧭【SC4】宅地の評価 ― 解法フレーム（2026-08-25 本人が整理／検証済み）

> **この5ステップの順序を崩さない。** 特に**①（評価単位）が最初**、**⑤（権利関係の減価）が最後**。

## ① 利用の単位で画地を切る（最重要・最初にやる）

**切る基準＝他人の「財産価値のある権利」が乗っているかどうか。**

| 状況 | 評価単位 |
|---|---|
| 自用地 ＋ 自用地 | **一体（1画地）** |
| 自用地 ＋ **使用貸借**で貸付 | **一体（1画地）** ← 使用借権はゼロ評価だから |
| 自用地 ＋ 貸宅地（借地権設定） | **別々** |
| 自用地 ＋ 貸家建付地 | **別々** |
| 貸家建付地 ＋ 貸家建付地（借家人が別） | **別々** |

**★使用貸借は「貸している」が「権利を渡していない」**＝評価は自用地のまま。ここが賃貸借との決定的な違い。

## ② 切った単位ごとに、間口・奥行を測り直す

**元の筆の形ではなく、画地の形で測る。** 切り方が変われば間口も接する路線も変わる。

## ③ 正面路線を決める

**正面路線＝「路線価 × 奥行価格補正率」が最大の路線。路線価そのものの大小ではない。**
奥行が深すぎ／浅すぎると補正率が下がるので、**路線価が高くても正面にならないことがある**。

## ④ 側方・二方の加算

```
1㎡当たり ＝ 正面路線価×奥行価格補正率
           ＋ 側方路線価×奥行価格補正率×側方路線影響加算率
           （＋ 裏面路線価×奥行価格補正率×二方路線影響加算率）
評価額 ＝ 上記 × 地積
```

- **角地**（別々の2路線が交差）／**準角地**（同一路線が屈折した内側）で加算率が違う
- **加算率の数値は暗記不要＝本番では地区区分ごとの表が与えられる**。覚えるのは**角地か準角地かの判定**と**式の形**
- 側方路線に画地の**一部しか接していない**場合は〔接する距離 ÷ 間口距離〕で按分してから加算

### 🔴🔴 勘違いポイント（本人申告 2026-08-25）

```
正しい： 正面路線価×奥行補正 ＋ 側方路線価×奥行補正×加算率
誤り　： 正面路線価×奥行補正 ×（1＋加算率）      ← これで計算していた
```

**★この2つは「正面路線価＝側方路線価」のときだけ答えが一致する。だから普段は気づかない。**
2026①（正面450千円・側方200千円）＝正しい**456千円** vs 誤り**463.5千円**。

**★なぜ側方路線価に掛けるのか**＝側方路線影響加算は「**角地であることによる増価**」で、その増価は
**側方路線の価値水準に比例する**。正面路線価に掛けると、側方路線が450千円でも200千円でも
同じ増価になり、意味をなさない。

## ⑤ 最後に権利関係の減価を掛ける

| 区分 | 算式 | 2026①の値 |
|---|---|---|
| 自用地 | 自用地価額 × 1.0 | |
| **貸宅地** | × **(1 − Ａ)** | ×0.5＝**50%減** |
| **貸家建付地** | × **(1 − Ａ×Ｂ×Ｃ)** | ×0.85＝**15%減** |
| 借地権 | × Ａ | |
| 貸家建付借地権 | × Ａ × **(1 − Ｂ×Ｃ)** | |

※Ａ＝借地権割合／Ｂ＝借家権割合／Ｃ＝賃貸割合

### 🔴🔴 勘違いポイント（本人申告 2026-08-25）

**貸家建付地は ×0.85。(1 − 借家権割合)＝0.7 ではない。**
**3つ全部を掛けてから1から引く**（1 − 0.5×0.3×1.0 ＝ 0.85）。

**★なぜ借地権割合を掛けるのか**＝貸家建付地は**自分の土地に自分の建物を建てて、その建物を貸している**土地で、
**土地には借地権を設定していない**。ただ借家人がいる以上、その人は建物を通じて土地を使っている。
その権利の大きさは**借地権そのものではなく、借地権のうち借家権割合に相当する部分**なので、**15%しか減らない**。

**★★検算に使える不等式＝貸家建付地の減価は、必ず貸宅地より小さい**（Ｂ×Ｃ≦1 なので Ａ×Ｂ×Ｃ≦Ａ）。
→ **答えを出したら「貸宅地より減価が小さいか」を確認する。**
