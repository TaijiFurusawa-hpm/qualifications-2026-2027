## 1. 【Q38 上場株式】パターン軸 ― 課税時期がどこにあるか

### 時系列

```
──────┬──────────┬──────────────┬─────────→
   配当落ち日      基準日           効力発生日
   (2026① 3/27)  (3/31)          (5/29)
      Ａ  │    Ｂ    │      Ｃ       │    Ｄ
```

| パターン | 課税時期の位置 | 株価の扱い | 加算するもの |
|---|---|---|---|
| **Ａ** | 配当落ち日**より前** | 配当込みの株価 | なし（権利未確定） |
| **Ｂ** | 配当落ち日〜基準日 | **月平均額の調整が要るはず**（財基通172・**要確認**） | なし |
| **Ｃ** | 基準日の翌日〜効力発生日前 | 配当落ち後の株価そのまま | **配当期待権**（予想配当−源泉） |
| **Ｄ** | 効力発生日以後で未受領 | そのまま | **未収配当金**（**要確認**） |

**2026① Q38 は パターンＣ。**

### ★★最重要の再解釈 ―「撹乱データ」ではなく「別パターン用のデータ」

2026① Q38 の株価表には次の2行がある。**パターンＣでは使わない。**

```
2026年3月1日から同月26日までの平均額   505円   ← 配当落ち日の前日まで
2026年3月27日から同月31日までの平均額  470円   ← 配当落ち日以後
```

**8/26の初回分析ではこれを「撹乱データ」と書いたが、その理解は浅い可能性が高い。**
配当落ち日（3/27）で期間が切られているのは偶然ではなく、**パターンＢで月平均額を調整するための材料**とみられる。

**→ 最初にやること＝財産評価基本通達172（上場株式の月平均額の特例）を原典で確認し、
パターンＢで505円・470円のどちらをどう使うのかを確定する。**
確定するまでは「撹乱データ」と断定しない。

### 直交する第2の軸 ― 課税時期に取引があるか

| | 扱い |
|---|---|
| 取引あり | その日の終値 |
| 取引なし・前後が同日数 | **前後の平均**（2026①＝4/28 472円と4/30 478円 → 475円） |
| 取引なし・前後の距離が違う | **近い方だけ** |

**→ シミュレーションは〔配当4パターン〕×〔取引3パターン〕で設計する。**

### 変えて試すべき設定（クイズ／ポッドキャストの素材）

1. 課税時期を **3/20**（＝パターンＢ）にしたら → 505円・470円をどう使うか
2. 課税時期を **6/10**（＝効力発生日5/29の後）にしたら → 配当期待権か未収配当金か
3. 課税時期を **3/10**（＝パターンＡ）にしたら → 加算なし・月平均額はそのまま
4. 4/29 に取引があった場合 → 前後平均を使わず終値
5. 4/28 が取引なしで 4/25 と 4/30 だった場合 → **4/30だけ**（近い方）

## 2. 【Q39 外貨建て財産】パターン軸 ― 3つの分岐

| 軸 | 分岐 | 使うレート |
|---|---|---|
| **為替予約** | 締結**していない** | **TTB** |
| | 締結**している** | **予約レート**（**要確認**） |
| **財産か債務か** | 財産（預金・債券等） | **TTB** |
| | **債務**（外貨建ての借入金等） | **TTS**（**要確認**） |
| **課税時期の公表** | あり | その日のTTB |
| | なし（休日等） | **課税時期"前"の最も近い日** |

**2026① Q39 は〔予約なし × 財産 × 公表なし〕。**

**★設問の注記「宇野さんはこの外貨普通預金について、為替予約は締結していない」が、パターン判定の合図。**
この一文があるということは、**締結していれば扱いが変わる**ということ。

### 🔴 最大の罠（既に判明・維持する）

| 財産 | 課税時期に公表/取引がないとき |
|---|---|
| **上場株式**（Q38） | 課税時期の**前後**で最も近い日 |
| **外貨建て財産**（Q39） | 課税時期**前**の最も近い日（**後ろは見ない**） |

**同じ大問の中で規則が割れている。** 2026① Q39 で 7,740,000円（6/22月曜のTTB）を選ぶと、株式のルールを外貨へ持ち込んだことになる。

### 変えて試すべき設定

1. 為替予約が締結されている場合
2. 外貨建ての**債務**（TTSになるか）
3. 課税時期が平日で公表がある場合
4. **既経過利子を考慮する**場合（2026①は「考慮しない」と明示されている＝考慮する版がありうる）

## 3. 【Q40 債券】パターン軸 ― 債券の種類ごとに評価方法が違う

**★これが最大の拡張ポイント。2026①は「個人向け国債」だが、種類が変われば式ごと変わる。**

| 債券の種類 | 評価方法 | 状態 |
|---|---|---|
| **個人向け国債** | **額面 ＋ 経過利子相当額 − 中途換金調整額**（＝中途換金価額） | ✅ 2026①で確認済み |
| 上場されている利付公社債 | 市場価格＋既経過利子（**要確認**） | ⏳ 未確認 |
| 上場されていない利付公社債 | 発行価額または額面＋既経過利子（**要確認**） | ⏳ 未確認 |
| 割引債 | （**要確認**） | ⏳ 未確認 |
| 転換社債 | （**要確認**） | ⏳ 未確認 |

**→ 「個人向け国債＝中途換金価額」だけを覚えると、種類が変わった瞬間に外れる。
まず種類を確定し、それから式を選ぶ形にする。**

### 使わないデータの扱い（既に判明・維持する）

2026① Q40 の「相続開始日より前までの受取利子の累計額 45,750円」は**使わない**（受取済みで国債の価値ではない）。
誤答肢 5,071,973円 は、まさにこれを足したもの。

## 4. 3問に共通する設計思想（クイズ・ポッドキャストの芯）

```
① 財産の種類を確定する
② その種類が、どのパターンに当たるかを判定する
     株式  → 課税時期は配当落ち・基準日・効力発生日のどこにあるか／取引はあるか
     外貨  → 為替予約はあるか／財産か債務か／公表はあるか
     債券  → どの種類の債券か
③ ★パターンが決まってから、はじめて式を選ぶ
④ ★そのパターンが要求する数値だけを表から拾う（使わない行が必ずある）
⑤ ★設問文が「課税価格に算入される財産の」と言っていたら、本体以外に
   加算するものがないか確認する（配当期待権・既経過利子など）
```

**→「暗記」ではなく「判定」の帯。フレームもクイズも、この5段で作る。**
