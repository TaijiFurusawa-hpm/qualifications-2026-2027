**各HTMLで実装を書き起こさないこと。必ずこのファイルからコピーする。**

**根本原因＝実装が各HTMLに散在し、新規作成のたびに書き起こしていたこと。**

### v2 の方針

1. **構造非依存** ― `.prompt` ラッパーがあってもなくても正しく拾う
   （`closest('.prompt')` → 無ければ `previousElementSibling` を遡る）
2. **fail loud** ― 見つからなければ**黙って別のものをコピーせず**、ボタンに「コピー元が見つかりません」と出す
   （v1は**静かに間違ったものをコピー**していたので気づけなかった）

### ⚠️ 編集時の注意

**このファイル内に script の終了タグを literal で書かないこと。**
HTMLに埋め込むとHTMLパーサがそこで script を終端し、**リスナーが一切登録されない**。
（2026-08-25 に実際に踏んだ。検証スクリプトが検出した）

### HTML側の作法

```html
<div class="prompt">
<pre>プロンプト本文…</pre>
<button class="copy">コピー</button>
</div>
```

CSSに `.copy.fail` と `.prompt` を用意しておくこと。

## verify-copy-buttons.py ― 挙動の検証（★HTMLを触ったら必ず通す）

```bash
cd certifications/CFP
python3 tools/verify-copy-buttons.py                 # 全ファイル
python3 tools/verify-copy-buttons.py 特定.html        # 個別
```

### ★「ボタンが何個あるか」を数える検証はしない

v1のバグは**ボタン数を数える検証では検出できなかった**（6個あることは確認していたが、
**6個とも同じものをコピーしていた**）。だからこのスクリプトは
**headless Chrome で実際に全ボタンをクリックし、コピーされた文字列を回収して照合**する。

- `navigator.clipboard.writeText` を差し替えて記録
- **`document.execCommand('copy')` のフォールバック経路も捕捉**
  （headless / file:// では `navigator.clipboard` が無く、こちらに落ちるため）
- 検出する異常＝①ボタン数とpre数の不一致 ②コピーが実行されない（＝コピー元が見つからない／リスナー未登録）
  ③**重複コピー**（別ボタンが同じものをコピー）④**n番目のボタンとn番目のpreの対応ズレ**
