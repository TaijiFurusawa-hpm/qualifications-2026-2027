## ① 生保商品・約款・法令（R1／R9）※設問帯 1〜4・31〜33
（商品種類・契約者保護・約款条項・募集ルール・保険業法・保険法・生保／損保の契約者保護機構）

- ◆**26①Q2** ✗「告知義務違反で解除されたら保険金は出ない」 → ◯**因果関係不存在特則**＝告知されなかった事実と支払事由に**因果関係がなければ保険金は支払われる**（保険法59条2項但書）。／同問の正解肢＝**介入権の行使には保険契約者の同意が必要**（不要と書いてあれば誤り）。
- ◆**26①Q3** ✗ 標準利率＝10年国債利回りの過去3年平均と過去10年平均の「高い方」 → ◯**低い方**を基準に設定する。
- ◆**26①Q3（併）** ✗「予定死亡率を低くすれば保険料は安い」 → ◯**個人年金（生存保障）は逆**。予定死亡率↓＝長生き前提＝保険料**高**。予定利率↓も保険料**高**。死亡保険と逆向きになるのが年金。
- ◆**26①Q12** ✗ 高予定利率契約の補償率を「80%−{(過去3年…)÷2}」 → ◯**90%−{(過去5年間の各年の予定利率−基準利率)の総和÷2}**。高予定利率契約の定義も**過去5年間**常に基準利率超。数字を丸暗記する。
- ◆**26①Q19** ✗ 制度共済は「保険業法の適用対象だが保険法の適用対象外」 → ◯**逆**。JA共済・こくみん共済coop・都道府県民共済は各根拠法に基づくため**保険業法は適用されない**が、**保険法は共済契約にも適用される**。
- ◆**26①Q33** ✗ 財形貯蓄傷害保険にも意向把握義務が適用される → ◯**財形貯蓄傷害保険は意向把握義務の適用除外**。情報提供義務・意向把握義務は「誰に・どの商品で」除外されるかをセットで覚える。

- ◆**25②Q1** ✗「復活は未払保険料を払い込めばよく、告知や医師の診査は不要」を適切と判断 → ◯**復活には告知（必要に応じて医師の診査）が要る**。失効前の状態に戻す制度だが、健康状態の再確認は必須。／同問の正解肢＝**保険期間中に受け取る配当金には所得税・住民税は課税されない**。
- ◆**25②Q2** ✗ ディスクロージャーの用語で「保有契約高」を不適切と判断 → ◯**EV（エンベディッド・バリュー）は「業界統一の技術的手法」では算出しない**（算出方法は各社で異なる）＝これが不適切。EV＝修正純資産＋保有契約価値という構成自体は正しい。**「統一」「一律」という語が出たら疑う**。
- ◆**25②Q33** ✗ 損保の紛争解決機関 → ◯**そんぽADRセンター／保険オンブズマンの守備範囲**（外資系損保・保険仲立人は保険オンブズマン）。機関名と対象の対応を暗記する。

## ② 生保と税務 ★★計算の主戦場（R2／R3）※設問帯 5〜10
（一時所得・雑所得・生命保険料控除・医療費控除・給付金の非課税）

> **⚠️ このセクションの3問（Q6・Q7・Q8）は共通の失点構造＝「ロジックが不確か → 計算が合わない → 選択肢に合う数字を作りにいく（数字合わせ）」**（本人申告）。**選んだ肢から原因を逆算すると真因を取り違える**ので、必ず「どのステップで詰まったか」で記録する。
> **🧩 クイズ化済＝[R1〜R17](quiz/index.html)（ステップ分解型）**：R1-R5 生保料控除（R5＝Q6の設例）／R6-R10 個人年金の雑所得（R10＝Q7の設例）／R11-R16 一時所得（R15＝Q8の設例）／**R17＝数字合わせへの対処**。

- ★**26①Q6**（生保料控除・104,500円）**【真因】✗ 毎年自動更新する団体定期保険を旧制度として計算** → 数字が合わず、**辻褄合わせに医療保険（損保会社の商品）を対象外と判断**して76,500円。
  → ◯**毎年自動更新の団体定期は更新のたびに新契約＝新制度**（2002年加入でも新制度で計算）。**損保会社が販売する医療保険も介護医療保険料控除の対象**。**自動振替貸付で充当された保険料もその年の支払保険料**。**3つとも「区分の仕分け」の論点＝控除額の計算式より手前で決まる**。
- ★**26①Q7**（雑所得・159.05万円）**【真因】✗ 必要経費の計算ロジック（年金総支給見込額の作り方）が入っておらず正確に計算できない** → 個人年金の数値が出せないまま、**企業型DCを私的年金として処理する形で数字を合わせた**（134.05万円）。
  → ◯**まず「公的年金等／私的年金／非課税」に3分類**（DCの年金は**公的年金等**・財形年金は**非課税**）。私的年金だけ `必要経費＝年金年額×(払込保険料総額÷年金総支給見込額)`。**総支給見込額＝基本年金額×(余命年数と保証期間の長い方)**（配当は入れない）。
- ★**26①Q8**（一時所得・200万円）**【真因】✗ ①養老保険（契約者変更あり）の一時所得の算出ロジックを誤った** ＋ **④一時払終身保険を金融類似商品として除外した**の**2論点が重なった**。
  → ◯①**保険料負担者ごとに按分**：収入800×(自己負担300/総額600)＝400万、経費は自己負担300万 → 一時所得**100万**。残り400万円は**父からの贈与（贈与税）**。／④**一時払「終身」保険は金融類似商品にならない**（満期がないため）＝5年以内解約でも**一時所得**。**月払いの変額保険（有期）も一時払等でないため対象外**。
- ◆**26①Q1** ✗ 据置期間中の年金は「入金がなければ課税されない」 → ◯**年金支払日の属する年の所得**として課税（権利確定主義）。同問の正解肢＝**年末調整後に保険料の割戻しを受けたら確定申告で修正が必要**（「提出期限が過ぎていれば不要」は誤り）。
- ◆**26①Q13** ✗ 資料（支払調書）に書いてある内容を読まずに知識で判断 → ◯**相続・贈与に係る年金の支払調書は金額基準なしで提出義務**（「年100万円以下なら不要」は誤り）。設例に資料が付く問題は**まず資料の但し書きを読む**。
- ◆**26①Q14** ✗ 保証期間分を繰上げ請求して一時金で受け取ったら一時所得 → ◯**雑所得**。／同問の正解肢＝**変額年金のファンド間スイッチングでは課税されない**（保険契約内の運用移動）。据置期間中（5年以内）の一部引出しは金融類似商品として源泉分離。

- ★**25②Q8（生保料控除・109,600円）【2回連続失点＝26①Q6に続く】** ✗ 113,600円。**真因は2つ**（本人申告）。
  - ✗**「介護保障保険」という名前で介護医療に入れた** → ◯**死亡保険金と介護保険金が同額で、各保障に応じた保険料の区分がない場合は、主たる保障が明確でないため「一般生命保険料控除」**。※対比＝**損保会社が売る医療保険は「介護医療」**（引受会社でなく保障内容で決まる）。**どちらも「名前・会社で決めない」という同じ原則の裏表**。
  - ✗**未払いの12月分を含めて計算した** → ◯**その年に実際に支払った額のみ**（66,000円）。72,000円だと個人年金が43,000円となり**111,100円**の誤答肢に着地する。※逆に**自動振替貸付で充当された保険料は「支払った」ものとして含める**。
  - ◆**新旧は別々の速算表で控除額まで出してから比べる**（足してから表に入れることはない）。一般＝②旧84,000→**46,000**／③新23,800→21,900／併用は**上限40,000** → **旧のみ46,000円が最大＝③は使わない方が得**。介護医療＝①24,200〈自動更新＝新〉→**22,100**／個人年金＝④旧66,000→**41,500**。合計**109,600円**。
  - ✅ **①団体医療の「自動更新＝新制度」は今回クリアできた**（26①Q6の失点論点＝クイズR1で潰した効果）。
- ★**25②Q5（雑所得・102.22万円）【2回連続＝26①Q7と同型】** ✗ 111.10万円。**真因＝必要経費の算出アルゴリズムが頭に入っておらず、時間もかかった**（本人申告）。迷った点＝①**余命年数の起点は契約時か現在か**（正＝**年金の支給開始日における年齢**）／②**契約種別によって余命年数を使うのか保証期間・支払期間を使うのか**（正＝**終身年金は「余命年数と保証期間の長い方」／確定年金は確定期間**）。抜けていた論点＝**企業型DCは公的年金等**。→ ◯**3階建てで積む**。①公的年金等＝老齢年金180万＋**企業年金（企業型DC）30万も公的年金等**＝210万 → 65歳以上・330万以下で控除110万 → **100万円**。②個人年金（5年保証付終身）＝30万−必要経費（500万÷(30万×**余命18年**)＝0.93 → 27.9万）＝**2.1万円**。③相続した年金＝課税部分1.2万−**必要経費1.08万（1.2×810/900）**＝**0.12万円**。→ **③の必要経費を落とすと103.42万円**になる。**余命年数は「支給開始日における年齢」で引く**（現在年齢ではない）。
- ★**25②Q6（一時所得・総所得算入305万円）【真因＝名義変更の按分】** ✗ 315万円。→ ◯**父から名義変更を受けた保険金は「負担割合」で按分する。「負担金額」を引くのではない**。満期700万・払込総額500万（父200万・本人300万）→ **総収入金額＝700万×(300万÷500万)＝420万円**／必要経費＝本人負担の300万円 → 差益**120万円**。**父の負担分に対応する700万×0.4＝280万円は贈与税**の対象（所得税ではない）。※名義変更が**相続・遺贈による場合は扱いが変わる**ので、まず変更の原因を確認する。
  - **通し**：①120万＋②▲20万（養老の損失は一時所得内で通算）＋③**500万**＋④60万＝660万 →（660−50）×**1/2**＝**305万円**。
  - ◆**③の契約者貸付金は「控除前の1,000万円」が総収入金額**（貸付金は借入金で、保険金と相殺されただけ）。940万で計算すると差益440万→**315万円＝実際に選んだ誤答**に着地する。
  - ◆**④一時払終身保険は金融類似商品に該当しない**ため、5年以内の解約でも源泉分離ではなく**一時所得**（金融類似商品＝一時払養老保険・一時払損害保険等）。
- ★**25②Q7（医療費控除）＝結果的に正答だが計算は誤っていた（2論点）**。採点上は見えないが**次に同じ設例が出たら落とす**。
  - ✗**自家用車の通院費を対象に含めた** → ◯**ガソリン代・駐車場代・高速道路料金は対象外**。対象は**公共交通機関（電車・バス）**。タクシーは**公共交通機関が使えない事情がある場合のみ**。
  - ✗**選定療養費を対象外とした** → ◯**2024年（令和6年）10月導入の「先発医薬品（長期収載品）を希望した場合の特別の料金」は医療費控除の対象**。国税庁の見解＝**先発医薬品の価格の一部に相当する額の支払い＝治療・療養に必要な医薬品の購入の対価**。**「保険外だから対象外」と反射しない**＝判定軸は【治療・療養に必要な対価か】。
