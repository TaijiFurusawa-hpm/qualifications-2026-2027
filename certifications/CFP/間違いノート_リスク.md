## ① 生保商品・約款・法令（R1／R9）※設問帯 1〜4・31〜33
（商品種類・契約者保護・約款条項・募集ルール・保険業法・保険法・生保／損保の契約者保護機構）

- ◆**26①Q2** ✗「告知義務違反で解除されたら保険金は出ない」 → ◯**因果関係不存在特則**＝告知されなかった事実と支払事由に**因果関係がなければ保険金は支払われる**（保険法59条2項但書）。／同問の正解肢＝**介入権の行使には保険契約者の同意が必要**（不要と書いてあれば誤り）。
- ◆**26①Q3** ✗ 標準利率＝10年国債利回りの過去3年平均と過去10年平均の「高い方」 → ◯**低い方**を基準に設定する。
- ◆**26①Q3（併）** ✗「予定死亡率を低くすれば保険料は安い」 → ◯**個人年金（生存保障）は逆**。予定死亡率↓＝長生き前提＝保険料**高**。予定利率↓も保険料**高**。死亡保険と逆向きになるのが年金。
- ◆**26①Q12** ✗ 高予定利率契約の補償率を「80%−{(過去3年…)÷2}」 → ◯**90%−{(過去5年間の各年の予定利率−基準利率)の総和÷2}**。高予定利率契約の定義も**過去5年間**常に基準利率超。数字を丸暗記する。
- ◆**26①Q19** ✗ 制度共済は「保険業法の適用対象だが保険法の適用対象外」 → ◯**逆**。JA共済・こくみん共済coop・都道府県民共済は各根拠法に基づくため**保険業法は適用されない**が、**保険法は共済契約にも適用される**。
- ◆**26①Q33** ✗ 財形貯蓄傷害保険にも意向把握義務が適用される → ◯**財形貯蓄傷害保険は意向把握義務の適用除外**。情報提供義務・意向把握義務は「誰に・どの商品で」除外されるかをセットで覚える。

## ② 生保と税務 ★★計算の主戦場（R2／R3）※設問帯 5〜10
（一時所得・雑所得・生命保険料控除・医療費控除・給付金の非課税）

- ★**26①Q6**（生保料控除・104,500円）✗ 医療保険を控除対象から除外して 76,500円 → ◯**損害保険会社が販売する医療保険も「介護医療保険料控除」の対象**。／併せて、**毎年自動更新する団体定期（2002年契約）は更新時に新契約扱い＝新制度**、**自動振替貸付で充当された保険料もその年の支払保険料**として控除対象。
- ★**26①Q7**（雑所得・159.05万円）✗ 企業型DCの年金100万円を「必要経費を引く私的年金」として処理 → ◯**確定拠出年金から支給される年金は公的年金等**。公的年金＋企業年金＝260万円をまとめて公的年金等控除（65歳以上・330万円以下＝**110万円**）で計算する。／財形年金貯蓄は要件を満たせば**非課税＝雑所得ゼロ**。
- ★**26①Q8**（一時所得・200万円）✗ 契約者変更のあった養老保険で払込総額600万円を全額控除し 800−600＝200万 → ◯**保険料負担者ごとに按分**。宮野さん負担300万/全体600万＝1/2 → 収入800×1/2＝400万・経費300万 → 一時所得100万。**父が負担した部分に対応する400万円は贈与税**。
- ★**26①Q8（併）** ✗ 一時払終身保険を4年9ヵ月で解約＝金融類似商品 → ◯**金融類似商品は一時払「養老」・一時払変額(有期)等＝満期のあるもの。終身保険は5年以内解約でも一時所得**。／**月払いの変額保険（有期）も金融類似商品にならない**（一時払等でないため）。
- ◆**26①Q1** ✗ 据置期間中の年金は「入金がなければ課税されない」 → ◯**年金支払日の属する年の所得**として課税（権利確定主義）。同問の正解肢＝**年末調整後に保険料の割戻しを受けたら確定申告で修正が必要**（「提出期限が過ぎていれば不要」は誤り）。
- ◆**26①Q13** ✗ 資料（支払調書）に書いてある内容を読まずに知識で判断 → ◯**相続・贈与に係る年金の支払調書は金額基準なしで提出義務**（「年100万円以下なら不要」は誤り）。設例に資料が付く問題は**まず資料の但し書きを読む**。
- ◆**26①Q14** ✗ 保証期間分を繰上げ請求して一時金で受け取ったら一時所得 → ◯**雑所得**。／同問の正解肢＝**変額年金のファンド間スイッチングでは課税されない**（保険契約内の運用移動）。据置期間中（5年以内）の一部引出しは金融類似商品として源泉分離。

## ④ 生保を使った相続対策（R2／R4）※設問帯 19〜24 ＝高配点ゾーン
（死亡保険金の非課税枠・契約形態と課税関係・納税資金対策・生前贈与プラン）

- ★**26①Q20**（9,250万円）✗ 非課税枠の按分の分母に**孫（相続人以外）の受取額を入れた** → ◯**分母は「相続人が受け取った保険金の合計」のみ**。孫が受け取った1,000万円×2は分母から除く。／死亡退職金の非課税枠は生命保険金とは**別枠で500万×法定相続人数**。役員退職慰労金規程で受給者（＝配偶者が第一順位）を確認してから按分する。
- ★**26①Q21**（1,250万円）✗ 解約返戻金だけで評価 → ◯**生命保険契約に関する権利＝解約返戻金＋前納保険料＋積立配当金−源泉徴収されるべき所得税額**。加算項目を落とさない。
- ◆**26①Q22** ✗ 代償財産として不動産を現物交付＝「取得した時点の価格」で評価 → ◯**交付時の時価**で譲渡があったものとされ**譲渡所得が課税**される。／譲渡に係る所得税相当額は相続税額から控除できない。分割払いには相続人全員の合意は要るが**家裁の許可は不要**。
- ◆**26①Q23** ✗ 孫を養子にすれば2割加算を免れる → ◯**孫養子は2割加算の対象**（代襲相続人である場合のみ除外）。／実子がいる場合、非課税枠の法定相続人に算入できる養子は**1人まで**。／死亡保険金を受け取った孫は「遺贈により財産を取得した者」＝**生前贈与加算の対象**になる。

## ⑤ 法人保険の経理処理 ★★最頻（R4）※設問帯 25〜30

- ★**26①Q27**（支払478,624／前払1,862,976）✗ 最高解約返戻率を**85%以下と誤読して資産計上60%**（936,640／1,404,960）を選択 → ◯表の**最大値88.4%＝85%超区分**。当初10年は**保険料×最高解約返戻率×90%**を資産計上。**表の最大値を丸で囲んでから区分を決める**のが第一手。
- ★**26①Q30**（退職金480,000／現金480,000）✗ 死亡保険金200万円を法人の**雑収入**に立て、退職金320万円を全額計上 → ◯**福利厚生プランの死亡保険金は遺族へ直接支払われ法人を通らない＝雑収入は立たない**。資産計上していた保険積立金（7万×1/2×12年＝42万円）を**雑損失**で取崩すのみ。会社が現金で払う退職金＝320万−中退共72万−保険金200万＝**48万円**。

## ⑨ 個人向け損害保険（R5／R6）※設問帯 37〜41

- ◆**26①Q37** ✗ 噴火・自動車の扱いで迷う → ◯**地震保険に自動車は含まれない**（家財の対象外）ので、地震でガレージが倒壊して車が壊れても地震保険は出ない。噴火・火砕流による焼失は**地震保険の対象**（火災保険では免責）。敷地内の自転車は**家財**として火災保険の対象。
- ◆**26①Q38** ✗ ファミリーバイク特約（人身傷害型）は対物事故を補償しないと判断 → ◯**ファミリーバイク特約は借用したバイクも対象で、対人・対物賠償は補償される**。「人身傷害型／自損事故型」の違いは**自分のケガの補償方法だけ**。
- ★**26①Q39** ✗ 別居の長男（29歳）を年齢条件（35歳以上）違反と判断 → ◯**運転者年齢条件は記名被保険者・配偶者・同居の親族に適用され、別居の未婚の子は年齢条件の適用外**。／正解肢＝**離婚歴のある別居の長女は「別居の未婚の子」に当たらず、家族限定特約の対象外**。**運転者限定は「同居／別居」「未婚（婚姻歴なし）」の2軸で機械的に判定する**。

## ⑩ 企業向け損保・新種保険（R6）※設問帯 40〜47

- ★**26①Q42**（1億円）✗ 時間切れで適当 → ◯**利益率＝(営業利益＋経常費)÷営業収益**＝(1+9)/20＝50%。喪失利益＝収益減少額4億×約定補償率50%＝2億、**支出を免れた経常費1億×(約定補償率÷利益率)＝1億を控除** → 1億円。約定補償率が利益率より大きいときのみ「利益率」に読み替える。
- ◆**26①Q43** ✗ 見舞金は補償対象外と判断 → ◯**サイバー保険は被害者への見舞金・原因調査費用・（特約付帯で）喪失利益を補償するが、ビジネスメール詐欺で詐取された金銭そのものは補償対象外**。

## ⑪ 法人損保の経理処理（R4）※設問帯 44〜47

- ★**26①Q46**（280万円）✗ 圧縮限度額の算式ミス（325万円） → ◯**保険差益＝保険金400−支出経費25−帳簿価額300＝75万円／圧縮限度額＝75×(取得価額350÷(400−25))＝70万円／帳簿価額＝350−70＝280万円**。分母は**保険金−支出経費**。

## ⑫ 個人・個人事業主の損保税務（R2／R5／R6）※設問帯 48〜50

- ◆**26①Q48** ✗ 時間切れ＋数値未整理 → ◯**住民税の地震保険料控除＝支払保険料×1/2、上限25,000円**（所得税は全額・上限50,000円）。店舗併用住宅で全額対象にできるのは居住用部分が**おおむね90%以上**（50%ではない）。複数年一括払いは**年数按分**した1年分。旧長期損害保険の経過措置は**2007年1月1日以後に契約変更していないこと**が要件。
- ◆**26①Q49** ✗ 時間切れ → ◯**人身傷害保険金のうち被保険者本人の過失割合に対応する部分は相続税の課税対象**（「過失割合にかかわらず全額非課税」は誤り）。相手方の過失部分＝損害賠償金相当＝非課税。
- ◆**26①Q50** ✗ 時間切れ → ◯**個人事業主は「事業に関するもの＝課税」**。棚卸資産（商品）の損害賠償金・休業補償（収益補償）・必要経費に算入した修理費を補填する車両保険金は**事業所得の収入金額**。非課税なのは**社会通念上相当額の見舞金**など身体・見舞に係るもの。
