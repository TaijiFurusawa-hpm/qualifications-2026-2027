1.2 2つの層：「静かな試験」と「手応えのある練習」

画面はどちらか一方の層に属します。実装では Fx.layer = "quiet" | "expressive" を画面の入口で切り替え、動き・音・触覚の呼び出しはすべてこの値を通します（個々の画面で判断しない）。

層属する画面
静かな試験層模試の準備・リスニング・切り替え・リーディング・解答状況。オンボーディングの実力チェック中もこの層。
手応えの練習層今日、Part別練習、解き直し、単語特訓、各結果画面（模試の結果を含む）、記録、レベル到達。

静かな試験層で起きること（これ以外は起きない）

動き

  • 選択肢の選択表示の切り替え（120ms、色と枠と印）
  • 音声の進み具合の棒（等速）
  • 画面の入れ替え（フェード150ms。横すべりなし）
  • 残り時間の数字の更新（1秒ごと。点滅しない）
  • 設問トレイの上げ下げ（指に追従）

音

  • リスニングの音声だけ。画面操作の音は設定がオンでも鳴らさない。

触覚

  • 選択肢を選んだときの軽い1回（設定「模試中の触覚」がオンのときだけ。既定はオフ）
  • それ以外なし（残り時間の知らせも触覚なし）

出さないもの：正誤、連続正解、紙吹雪、ほめ言葉、購入の案内、通知、評価の依頼、「おかしい」報告ボタン。

6推定スコア（目安の幅）の出し方

6.1前提：何が言えて、何が言えないか

  • この模試は自作で、本番のスコアと照らし合わせた調整（較正）をしていない。公式の換算表は非公開で、使わないと決めている。C決定L§6-1
  • だから言えるのは「この模試で何問正解したか」と「そこから仮の決まりで置きかえた点数の幅」まで。「本番で何点取れる」は言えない。
  • 点を1つだけ出すと、正確に見えてしまう。必ず幅で出し、幅の理由を画面で読めるようにする。L#4S-P11A-P6

6.2計算の手順

  1. セクションごとの正答数を数える。リスニング（Part 1〜4）とリーディング（Part 5〜7）、各100問。未解答は不正解として数える。音声が再生できず採点から外した問題があれば、残りの問題数での正答率を100問あたりに直す。
  2. 中心の点を出す（セクションごと）。正答数 r（0〜100）を、5〜495点の目盛りに直線で置く。5点きざみに丸める。 
    中心 = 5 + 4.9 × r　（r=0 → 5点、r=100 → 495点）
    これはこのアプリが仮に置いた決まりで、公式の換算ではない。回ごとの補正値（offset[n]、初期値0）を足せる形にしておき、較正のデータが集まったら直す。
  3. 幅を出す（セクションごと、±の片側）。3つの揺れを足し合わせる。 
    片側の幅 = 4.9 × √( ( 1.28² × 100 × p × (1−p) ＋ F² ) ÷ k ＋ B² )　→ 5点きざみに丸める

p = そのセクションの正答率（r ÷ 100）
k = 計算に使う模試の回数（1〜3）
F = 5問 … 回ごとの難しさの差（自作なので回によって難しさがそろっていない分）
B = 4問 … 全体のずれ（較正していないことによる、回数を重ねても消えない分）
  4. 合計にする。合計の中心＝2つの中心の和。合計の幅＝2つの幅の単純な和（全体のずれは両方に同じ向きに効くと考え、狭く見積もらない）。下は10点、上は990点で止める。
  5. 表示する。「目安 595〜765点」。下にリスニング 320〜400、リーディング 275〜365。
幅の部品何の揺れか大きさ回数を重ねると根拠
①問題数による揺れ100問という限られた数で測ることによる偶然のぶれ（当てずっぽうで当たる・うっかり外す）正答率50%で最大。標準的なぶれ5問に1.28を掛けた約6.4問√k で小さくなる正答率の標準誤差 √(p(1−p)/n) という一般的な統計の式
②回ごとの難しさの差 F模試3が模試1より難しい、といった差5問ぶん√k で小さくなる（ならされる）設計判断 仮の値
③全体のずれ B自作の模試が全体として本番より易しい・難しい可能性4問ぶん小さくならない設計判断 仮の値
F と B は、いまは根拠となる実測のない仮の値です。「幅を狭く見せない」側に倒して置いています。1.28 は「仮定が正しければ、およそ5回に4回は入る」幅に当たる倍率ですが、F と B が仮の値である以上、画面では確率の言い方をしません（「80%の確率で」などと書かない）。
